10. Python environment issues
-----------------------------
- Debian/Raspberry Pi system Python rejected system-wide pip installation with:
  externally-managed-environment
- Correct solution: use a virtual environment.
- Windows PowerShell also blocked Activate.ps1 because script execution was disabled.
- A temporary process-scoped PowerShell execution policy was used:
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
- This was safe and automatically expires when the PowerShell process closes.
- On Windows, the alternative is to run .venv\\Scripts\\python.exe directly without activation.
- On the Pi, use:
  python3 -m venv .venv
  source .venv/bin/activate
  python -m pip install -r requirements.txt
- The Windows .venv must never be copied to or reused on Linux.
